# Electrodes and reference

Measured electrodes: **Fp1, Fp2, F7, F8, F3, F4, C3, C4, Fz**.

The same common-average reference uses **F3, F4, F7, F8, C3, C4, Cz, P3, P4, O1, O2, T7, T8, P7, P8**. Older names T3/T4/T5/T6 map to T7/T8/P7/P8.

All nine measured electrodes and all fifteen reference electrodes were available in every included recording: 67 NESI files, eight MASS recordings and ten LENS recordings. MASS PSG has the required scalp electrodes.

The code uses 0.5-30 Hz for autocorrelation and wave shapes, and 0.5-4 Hz for trough detection. LENS original reference is assumed shared. NESI absolute voltage units remain unconfirmed. Model LFP is a single extracellular channel and has no common-average rereferencing.

The local electrode audit retains source header details and participant identifiers.
